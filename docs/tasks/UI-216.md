# UI-216 — Card army events on the map

## Goal

Client implementation: card army events (moves and attacks: Help Unlooked For, Paths of the Woses, Through a Day and a Night, Shadows Gather, The Shadow Lengthens, The Shadow is Moving, Corsairs of Umbar, Nazgûl manoeuvres, Grond, The Fighting Uruk-hai) use the map and region panel like an Army die, with progress, Skip manoeuvre and ✓ in the console.

## Context and dependencies

User request 2026-10-16: card choices about "what goes where" are handled in the fixed UI at the bottom with a Confirm choice option; one click on a highlighted figure, then distribute it on the board while the rules allow; fewest windows and clicks. Design: [CARD_CHOICES_UX](wotr-client:docs/ui/CARD_CHOICES_UX.md). Today EventArmyChoices / ArmyChoices / AttackChoices build a plan list and Confirm in the decision window.

## Logic and scope

- Movable armies highlighted; army click, figures in the region panel, destination click, as with an Army die (UI-105).
- Multi-army events show "Armies moved n/m" in the console; ↶ undoes the last army; Skip manoeuvre is a console option; ✓ sends.
- Attacks open the battle as today.

## Acceptance criteria

- CC08; every army event card of the base game resolves without the window for both sides.

## Verification

- EditMode: event army plan progress.
- PlayMode: army event packs (Strategy01–04) in four layouts; full EditMode.

## Documentation and handoff

Update: this file, `wotr-client:docs/ui/CARD_CHOICES_UX.md`, `wotr-client:docs/ui/ARMY_MAP_UX.md`, `docs/TESTING.md`, `docs/ROADMAP.md`.

## Result (2026-10-16)

`CardArmyEvent` and `CardArmyInteraction`: a card's army event is planned like an Army die. The event's armies glow;
a click on one starts its move with the whole army and opens its region panel, whose lit figures toggle;
destinations, routes and attack targets keep their map clicks; another lit army starts the next move. The event's
alternatives (another kind of army step, Skip maneuver) are console buttons, the console counts "Armies moved n of m",
↶ undoes the last step and ✓ sends. The tray builds no plan list, route label, figure grid or alternatives.
