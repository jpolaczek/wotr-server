# UI-210 — Card choices in the fixed UI: design and tasks

## Goal

Documentation task: the design for card decisions in the fixed UI (objects highlighted, one selection for many placements, options and Confirm choice in the console) with the inventory of base-game card decisions and the implementation tasks.

## Context and dependencies

Resumes the scope of UI-164 (paused 2026-10-14) and extends it. User request 2026-10-16: card choices about "what goes where" are handled in the fixed UI at the bottom with a Confirm choice option; one click on a highlighted figure, then distribute it on the board while the rules allow; fewest windows and clicks. Design: [CARD_CHOICES_UX](wotr-client:docs/ui/CARD_CHOICES_UX.md).

- The registry validates with the new tasks and dependencies.
