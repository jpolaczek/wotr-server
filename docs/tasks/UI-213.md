# UI-213 — Card recruitment from a highlighted Reserve with one selection

## Goal

Client implementation: card recruitment highlights the Reserve tab and the tokens the card may still place; an armed token stays armed while the card allows another; ✓ in the console (and the panel's ✓) sends.

## Context and dependencies

User request 2026-10-16: card choices about "what goes where" are handled in the fixed UI at the bottom with a Confirm choice option; one click on a highlighted figure, then distribute it on the board while the rules allow; fewest windows and clicks. Design: [CARD_CHOICES_UX](wotr-client:docs/ui/CARD_CHOICES_UX.md). Today EventRecruitDraft clears the armed token after each placement.

## Logic and scope

- Highlight the Reserve tab and eligible tokens while a card plan is open (classes shared with the Muster highlight).
- Keep the armed token after a placement while per-region, per-nation and total limits allow it; clear it when not; click on the armed token releases it.
- Region first stays supported; ↶ removes the last placement; progress "Recruited n/m" in the console.

## Acceptance criteria

- CC03 and CC04; a card with one fixed region (ReserveFigures) keeps its one-click choice.
- The armed token never places beyond a limit; the panel and console ✓ agree.

## Verification

- EditMode: EventRecruitDraft and RecruitEffectDraft tests for sticky placement and limits.
- PlayMode: card recruitment packs; full EditMode.

## Documentation and handoff

Update: this file, `wotr-client:docs/ui/CARD_CHOICES_UX.md`, `wotr-client:docs/ui/POLITICS_REINFORCEMENTS_UX.md`, `docs/TESTING.md`, `docs/ROADMAP.md`.

## Result (2026-10-16)

Client `8f42869`: `EventRecruitDraft.Drop` keeps an armed token armed with its group's next free figure while the
card's limits (per region, per nation, in total) leave it a region, and releases it at a limit, so it never places
beyond one. With a token armed, another token click switches it and a click on the armed token releases it; region
first is unchanged when nothing is armed. Choosable Reserve tokens carry `eligible-token` (tinted slot, full glow,
no size change) and the tab keeps `legal-target`. ↶ removes the last placement and re-arms the token. The console's
"Recruited n of m" and ✓ come from UI-211; the panel's ✓ sends the same plan. `ReserveFigures` keeps its one click.
