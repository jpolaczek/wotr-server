# UI-221 — Table effects unroll on hover like the hand

## Goal

Client implementation: the cards in play on the table (the Effects tab) unroll on hover like the hand's
cards in the bottom-right corner, and the Effects tab has a single close button on its right.

## Context and dependencies

The owner's request of 2026-10-17. This is a user-approved hover exception like the hand's unrolling
(UI-91) and the edge tabs (UI-92, UI-98); it shows the card's text only and sends nothing.

## Logic and scope

- Each table effect is a tile that unrolls upward/over its neighbours on hover or focus, with the same
  look, timing and reading width as the hand's cards; leaving it rolls it back without an action.
- Clicks keep their current meaning (pinning or using an effect where the server allows it).
- The Effects tab's header has one close button on the right; other header buttons go away.

## Acceptance criteria

- Hovering a table effect shows its full text like a hand card; nothing is sent by hovering.
- The Effects tab shows one close button, on the right.
