# UI-212 — Nazgûl flights on the map

## Goal

Client implementation: for Nazgûl Search, The Nazgûl Strike!, The Ringwraiths Are Abroad and The Black Captain Commands (fly) the movable Nazgûl are highlighted on the map; one click arms a stack, each destination click moves one Nazgûl; ✓ in the console sends.

## Context and dependencies

User request 2026-10-16: card choices about "what goes where" are handled in the fixed UI at the bottom with a Confirm choice option; one click on a highlighted figure, then distribute it on the board while the rules allow; fewest windows and clicks. Design: [CARD_CHOICES_UX](wotr-client:docs/ui/CARD_CHOICES_UX.md). Today the window lists Nazgûl as numbered portrait buttons with groups; map clicks set destinations only (FellowshipChoices, TravelDraft).

## Logic and scope

- Highlight every Nazgûl in ActionOption.Travel at its map position (army marker, lone figure, the Witch-king) and in the region panel.
- A click on a highlighted region or figure arms its unmoved Nazgûl; each lit destination click moves one; the source stays armed while it has an unmoved Nazgûl; another source switches.
- Ghosts at destinations, progress "Nazgûl moved n" in the console, ↶ undoes the last move, ✓ sends CompanionMoves (one group per origin and destination); zero moves allowed.
- No decision window; no server or Contracts change.

## Acceptance criteria

- CC01 and CC02 for both the Search and the Strike; the Witch-king can be moved on his own.
- Payload accepted by the server for moves from three regions in one decision.

## Verification

- EditMode: the distribution draft (arming, moves, undo, payload groups).
- PlayMode: Nazgûl card network tests (Shadow02 and Shadow04 packs) with map clicks and ✓ in the console; full EditMode.

## Documentation and handoff

## Result (2026-10-16)

Client `ce97905`: `NazgulFlightDraft` (presentation) and `NazgulFlightInteraction` (application). Movable Nazgûl
glow on their map markers and in the region panel. A click on a lit source arms its unmoved Nazgûl (ordinal order;
the Witch-king only as the region's last one or when his figure is clicked in the panel) and opens its panel; each
lit destination click flies one, the armed marker keeps the selected plinth, flown Nazgûl are ghosts at their
destinations, the console shows "Nazgûl moved n" and ↶ undoes the last flight (the armed source is part of the
draft: kept across a reconnect, never sent). The console's ✓ sends `CompanionMoves` with one group per origin,
garrison and destination. The flights build no window choices, and the effect trail of a card decision no longer
opens the window. CC02 (no move) is covered by the server's empty flight and the EditMode draft and hint; a second
network test on the same pre-created match is not possible. Moves from three regions in one decision: server test
`Shadow02TravelTests.OneDecisionFliesNazgulFromThreeRegions` (Search and Strike) with the payload shape the draft builds.
Left for UI-164: after the player's own ✓ the waiting side's window still opens for the effect trail alone (outside
card decisions the trail still counts as a choice, because the battle window's host depends on it).
