# UI-223 — Left rail tabs stand out from the map

## Goal

Client implementation and artwork: the tabs on the left edge of the board (Politics, Effects, Characters and the
others of the left rail) read clearly over any part of the map, and a tab whose panel can be used now is marked
unmistakably.

## Context and dependencies

The owner's request of 2026-10-17: over the map the tabs are barely visible; they should present themselves
more clearly against it and be marked more clearly when they can be used. UI-182 made the tabs bare enamelled
medallions; UI-193 gave usable tabs a gold glow (`available`).

## Logic and scope

- Each tab gets a backing that separates it from the map (a dark lacquer plate or a strong cast shadow) while
  keeping the medallion style; labels get contrast against any terrain.
- A usable tab gets a stronger, clearly visible mark (brighter glow and a contrasting rim), consistent with the
  other "you can act here" marks; Reduced motion keeps it static.
- Sizes and positions stay fixed (2026-10-14 layout rule).

## Acceptance criteria

- The tabs read clearly over light and dark parts of the map at 1366×768 and 1920×1080.
- A usable tab is distinguishable at a glance from an unusable one.

## Verification

- Art kit tests (UiArtKitTests) for new textures; visual check in the owner's build of the next release.
