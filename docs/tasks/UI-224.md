# UI-224 — Enterable and enemy regions pulse with a green or red glow

## Goal

Client implementation: regions the current action can enter (legal map targets) are marked more clearly with a
green glow that pulses gently, and enemy regions the action can attack get the same effect in red; both stay
distinct from hover and selection.

## Context and dependencies

The owner's requests of 2026-10-17 (green for enterable regions, then "the same effect for the enemy terrain
marked in red"). Today a target is a faint green fill (`MapRegionEmphasis.Target`, UI-73) and an attack target a
faint red one (`MapRegionEmphasis.Attack`).
R23: animations are short and gentle; Reduced motion is available.

## Logic and scope

- A legal target region gets a stronger green fill plus a green glow along its edge; the glow's opacity pulses
  slowly (about 1.5 s per cycle). An attack target gets the same stronger fill, edge glow and pulse in red; the
  selected and pressed states win as today.
- The pulse animates only a property of a retained layer (opacity), never repaints the region shapes per frame,
  and stops when no target is shown; with Reduced motion the glow stays static.
- Military targets, army destinations, recruitment settlements and Fellowship route steps all use the same mark.

## Acceptance criteria

- Enterable regions are clearly visible over the map at both resolutions with a gentle green pulse, attack
  targets with the same pulse in red.
- Pan and zoom do not repaint region layers; Reduced motion shows a static glow.

## Verification

- EditMode: emphasis colours and the pulse curve; PlayMode render counters where available; visual check in
  the next release.
